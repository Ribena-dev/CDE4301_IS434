The key insight: every number you need is in §2.6 and Tables 2-1 and 2-2. Nothing is hidden in other sections. The chapter gives you d₀ as a result (Figure 2-4), but all the inputs needed to reproduce it are listed in those two tables and the §2.6 paragraph.

Step 1 — Read D_x and D_y from Table 2-2 Table 2-2
Table 2-2 is titled "Aberration Coefficient for spaced oxford triplet extracted from PBO simulations." The very first two rows under "Demagnification (First order)" give you:
D_x = ⟨x|x⟩⁻¹ = 857
D_y = ⟨y|y⟩⁻¹ = −130

The negative sign on D_y means the image is inverted in Y.
For all size calculations, use |D_y| = 130.
What this notation means — Eq 2.12–2.13
The notation ⟨x|x⟩ is the (1,1) element of the system transfer matrix M. Its inverse is the demagnification. This comes from the matrix formalism in §2.5:
x_image = M · x_object
M = chain product of all quadrupole transfer matrices
D = (M₁₁)⁻¹ = ⟨x|x⟩⁻¹    (Eq 2.12)
Physical meaning of D = 857 vs D = 130
The object slit image is shrunk by 857× in X and 130× in Y. This asymmetry is deliberate — it comes from the spaced Oxford triplet geometry where lenses 1 and 2 are 18.5 cm apart (large gap creating a crossover in X), while lenses 2 and 3 are only 2.5 cm apart. The crossover in X acts as a second demagnification stage.
Source of asymmetry:   Table 2-1 spacing values
L₁₂ = 18.5 cm   (large → extra X demag via crossover)
L₂₃ = 2.5 cm    (small → no crossover in Y)
D_x = 857     D_y = 130     ✓ directly from Table 2-2, row 1
Step 2 — Extract α_obj from §2.6 text §2.6 text
In the §2.6 paragraph describing the PBO simulation, the chapter states: "A beam of 2 MeV protons passes through a objective aperture set to 8×4 µm² with a half angle beam divergence of 3 µrad."
α_obj = 3 µrad = 3 × 10⁻⁶ rad

This is the half-angle of the cone of rays entering the lenses.
It is set by the collimator aperture (§2.2, §2.3).
Where does 3 µrad come from physically?
The collimator half-width is c = 15 µm (half of 30×30 µm²) and sits approximately L = 1.1 m before the lenses (Figure 2-3). The geometric half-angle is:
α_obj = c / L = 15×10⁻⁶ / 1.1 = 13.6 µrad (geometric)

PBO uses 3 µrad — this is the effective value after the beam
profile is considered. The chapter gives 3 µrad as the simulation
input; use this value for all calculations.
Also extract slit and collimator sizes from same paragraph
Object slit (full):    8 × 4 µm²   → half-widths: s_x=4 µm, s_y=2 µm
Collimator (full):    30 × 30 µm² → half-width:   c = 15 µm
Both from the same sentence in §2.6.
α_obj = 3 × 10⁻⁶ rad    s_x = 4 µm    s_y = 2 µm    ✓ §2.6 text
Step 3 — Calculate α_img (convergence angle at sample)
This is the first calculation. No new numbers needed — just apply Liouville's theorem using D and α_obj from Steps 1 and 2.
Logic:Phase-space area ε = x·α is conserved through any lens
Setup:ε_obj = ε_img   →   a_obj·α_obj = a_img·α_img
Define:D = a_obj/a_img   →   a_obj = D·a_img
Sub in:D·a_img·α_obj = a_img·α_img
Cancel:α_img = α_obj · D
Apply numbers
X: α_x = 3×10⁻⁶ × 857
       = 2571×10⁻⁶ rad
       = 2.571 × 10⁻³ rad = 2.571 mrad

Y: α_y = 3×10⁻⁶ × 130
       = 390×10⁻⁶ rad
       = 0.390 × 10⁻³ rad = 0.390 mrad
Unit check
[rad] × [dimensionless] = [rad]   ✓
3×10⁻⁶ × 857 = 2.571×10⁻³       ✓
Ratio: α_x/α_y = 2.571/0.390 = 6.59 = D_x/D_y   ✓
α_x = 2.571 mrad    α_y = 0.390 mrad    ✓ calculated from Steps 1+2
Step 4 — Calculate d_geo (geometric spot size) §2.6 text
The object slit is a physical aperture of half-width s. The lens system creates a demagnified image of it on the sample. The full width of that image is d_geo.
Logic:Image half-width = object half-width / D
Half:a_img = s / D
Full:d_geo = 2·s / D    (full width = 2 × half-width)
Apply numbers — convert µm to nm first
s_x = 4 µm = 4000 nm    D_x = 857
d_geo_x = 2 × 4000 / 857 = 8000/857 = 9.34 nm

s_y = 2 µm = 2000 nm    D_y = 130
d_geo_y = 2 × 2000 / 130 = 4000/130 = 30.77 nm
Unit check
[nm] / [dimensionless] = [nm]   ✓
2×4000/857 = 9.334... ≈ 9.34 nm   ✓
2×2000/130 = 30.769... ≈ 30.77 nm   ✓

Note: d_geo_x ≈ 9.3 nm already matches Figure 2-4 spot.
This tells us the X spot is almost entirely geometric.
d_geo_x = 9.34 nm    d_geo_y = 30.77 nm    ✓ calculated from §2.6 slit sizes + Table 2-2 D values
Step 5 — Calculate d_chrom (chromatic aberration blur) Table 2-2 §2.6
From Table 2-2, rows labelled "Chromatic Aberration (Second order) (mm/mrad)":
⟨x|θδ⟩⁻¹ = −52 mm/mrad   →   C_c_x = |−52| = 52 mm/mrad
⟨y|θδ⟩⁻¹ = +126 mm/mrad →   C_c_y = |126|  = 126 mm/mrad
The formula and logic
Logic:Ions with energy E+ΔE focus at a different z.
 At nominal focus they arrive at offset x = C_c·α·δ
Formula:d_chrom = C_c · α_img · δ
Units:[mm/mrad] × [mrad] × [dimensionless] → mm → convert to nm
Apply numbers — careful with units
δ = 10 ppm = 10 × 10⁻⁶   (from §2.6: "10-ppm stability")

X: d_chrom_x = 52 [mm/mrad] × 2.571 [mrad] × 10×10⁻⁶
              = 52 × 2.571 × 10⁻⁵ mm
              = 1.337 × 10⁻³ mm = 1.337 × 10⁻³ × 10⁶ nm = 1.34 nm

Y: d_chrom_y = 126 × 0.390 × 10×10⁻⁶ mm
              = 4.914 × 10⁻⁴ mm = 0.49 nm
Unit conversion in full
C_c [mm/mrad] × α [mrad] × δ [dimensionless]
= mm   × 10⁶ nm/mm = nm   ✓

52 × 2.571 × 10⁻⁵ = 0.001337 mm × 10⁶ = 1337 pm = 1.34 nm
d_chrom_x = 1.34 nm    d_chrom_y = 0.49 nm    ✓ Table 2-2 coefficients + §2.6 δ
Step 6 — Calculate d_spher (spherical aberration blur) Table 2-2
From Table 2-2, rows labelled "Spherical Aberration (Third order) mm/mrad³". The dominant terms are:
⟨x|θ³⟩    = +24 mm/mrad³   →   C_s_x = 24 mm/mrad³
⟨y|θ²φ⟩ = −71 mm/mrad³   →   C_s_y = 71 mm/mrad³

⟨x|θφ²⟩ = 10.877 and ⟨y|φ³⟩ = −24 are smaller and mix planes.
For a first-order estimate, use the dominant term per axis.
The formula and logic
Logic:Off-axis rays focus to wrong position.
 Displacement ∝ angle³ (third-order aberration)
Formula:d_spher = C_s · α_img³
Units:[mm/mrad³] × [mrad]³ = mm → convert to nm
Apply numbers — cubing the angle
X: α_x³ = (2.571)³ = 16.99 mrad³
       d_spher_x = 24 × 16.99 × 10⁻³ mm  (mrad³ → factor 10⁻³ already in unit)
                  = wait — mrad = 10⁻³ rad, so mrad³ = 10⁻⁹ rad³
       d_spher_x = 24 [mm/mrad³] × (2.571×10⁻³ rad)³
                  = 24 × 16.99×10⁻⁹ mm
                  = 4.078×10⁻⁷ mm = 0.41 nm

Y: α_y³ = (0.390)³ = 0.05932 mrad³
       d_spher_y = 71 × (0.390×10⁻³)³ mm
                  = 71 × 5.932×10⁻¹¹ mm = 0.042 nm
d_spher_x = 0.41 nm    d_spher_y = 0.042 nm    ✓ Table 2-2 coefficients only
Step 7 — Assemble d₀ in quadrature (the key step)
All three contributions are independent Gaussian blurs. Independent Gaussian variances add — so in FWHM terms their squares add:
d₀ = √( d_geo² + d_chrom² + d_spher² )
X direction — full arithmetic
d_geo_x   = 9.34 nm     d_geo_x²   = 87.24 nm²
d_chrom_x = 1.34 nm     d_chrom_x² =  1.80 nm²
d_spher_x = 0.41 nm     d_spher_x² =  0.17 nm²
                         sum of squares = 89.21 nm²

d₀_x = √89.21 = 9.44 nm
Chapter Fig 2-4 reports 9.3 nm — within rounding of coefficients ✓
Y direction — full arithmetic
d_geo_y   = 30.77 nm   d_geo_y²   = 946.8 nm²
d_chrom_y =  0.49 nm   d_chrom_y² =   0.24 nm²
d_spher_y =  0.04 nm   d_spher_y² =   0.002 nm²
                        sum of squares = 947.0 nm²

d₀_y = √947.0 = 30.8 nm
Chapter reports 32 nm — small difference from higher-order
cross-terms ⟨y|θ²φ⟩ mixing X and Y divergence
Why X ≈ d_geo and Y ≈ d_geo + small corrections?
X: d_geo contributes 87.24/89.21 = 97.8% of d₀²
Y: d_geo contributes 946.8/947.0 = 99.98% of d₀²

Both spots are almost entirely geometric — the lenses are near-perfect
at these settings. Aberrations are negligible.
d₀_x = 9.44 nm ≈ 9.3 nm (Fig 2-4)    d₀_y = 30.8 nm ≈ 32 nm (Fig 2-4)    ✓
Step 8 — Calculate depth of focus from d₀ and α_img
Now that we have d₀ (Step 7) and α_img (Step 3), the depth of focus follows directly from the √2 criterion derivation:
Start:d(DoF) = √2 · d₀  (41% growth, Rayleigh criterion)
Sub:√2·d₀ = √(d₀² + (2α·DoF)²)
Square:2d₀² = d₀² + (2α·DoF)²
Simplify:d₀² = (2α·DoF)²
Solve:DoF = d₀ / (2α)
Apply numbers — convert to consistent units (metres)
X:
d₀_x = 9.44 nm = 9.44 × 10⁻⁹ m
α_x  = 2.571 × 10⁻³ rad
DoF_x = 9.44×10⁻⁹ / (2 × 2.571×10⁻³)
         = 9.44×10⁻⁹ / 5.142×10⁻³
         = 1.836×10⁻⁶ m = 1.84 µm

Y:
d₀_y = 30.8 nm = 30.8 × 10⁻⁹ m
α_y  = 0.390 × 10⁻³ rad
DoF_y = 30.8×10⁻⁹ / (2 × 0.390×10⁻³)
         = 30.8×10⁻⁹ / 7.80×10⁻⁴
         = 3.95×10⁻⁵ m = 39.5 µm
Unit check
[m] / [rad] = [m]   ✓  (rad is dimensionless)
9.44×10⁻⁹ / (5.142×10⁻³) = 1.836×10⁻⁶ m = 1.84 µm   ✓

Using chapter's d₀ values (9.3, 32 nm) gives DoF_x=1.81 µm, DoF_y=41 µm
DoF_x = 1.84 µm    DoF_y = 39.5 µm    ✓ calculated purely from previous steps
