## Annex A: Software Overview

Although not part of main project, to speed up analysis process and produce repeatable results, I have scripted an automated analysis tool aiming to automatically process data files. The software workflow processes SEM images, extracts intensity profiles, applies edge detection algorithms, and fits mathematical models to determine FWHM values with minimal user intervention.
